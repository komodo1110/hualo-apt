# Política de seguridad

## Reportar una vulnerabilidad

Si encuentras una vulnerabilidad de seguridad en este repositorio (por
ejemplo, un paquete comprometido, una firma inválida, o una clave
expuesta), repórtala de forma privada abriendo un
[security advisory](https://github.com/komodo1110/hualo-apt/security/advisories/new)
en lugar de un issue público.

## Clave GPG comprometida

Si sospechas que la clave privada del repositorio fue expuesta, repórtalo
de inmediato. La clave será rotada y se notificará a los usuarios para
que reimporten la nueva clave pública.
