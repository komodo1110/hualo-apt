# Contribuir

Gracias por tu interés en contribuir al repositorio de paquetes de HuaLo.

## Reportar un problema

Abre un [issue](https://github.com/komodo1110/hualo-apt/issues) describiendo:
- Paquete y versión afectados
- Qué esperabas que pasara y qué pasó
- Pasos para reproducirlo

## Proponer un paquete nuevo

1. Abre un issue describiendo el paquete, su propósito y licencia.
2. Si se aprueba, se te indicará el proceso para subir el `.deb`
   correspondiente.
3. Todos los paquetes deben cumplir con los estándares de control de
   Debian (`dpkg-deb --info`) y estar libres de binarios sin licencia clara.

## Código de conducta

Sé respetuoso. Los issues o pull requests con lenguaje ofensivo serán
cerrados.
